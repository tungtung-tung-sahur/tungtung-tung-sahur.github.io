System Requirements

Everything you need to know before you load the game. Minimum and recommended specs for every platform, browser compatibility, performance bottlenecks, and the fastest fixes for lag and stutter. No guesswork — just what actually matters.

⚡ Quick Verdict

Four facts that answer the most common question — "can I run this?" — before you read a single spec sheet.

Best Browser

If your device was made in the last five years and can run a modern browser without freezing, it will run this game. The browser version is the lightest — it is designed to work on school laptops, old Android phones, and tablets that were never meant for gaming. The mobile app versions ask for slightly more. The 3D Horror version is the heaviest and the only one that may stutter on very old hardware.

The specs below are split into minimum and recommended. The minimum is what you need for the game to launch and function. The recommended is what you need for it to feel good — smooth camera movement, no dropped inputs, and steady frame rate during the chase sequences. If you are between the two, you can play. You just may see occasional stutter in the Graveyard and the Mansion.

📊 Minimum vs Recommended

The line between "it runs" and "it feels right". If you can hit the recommended column, you will not lose a single run to input lag.

⚠️ Minimum — It Runs

  • Processor Dual-core 1.6 GHz or equivalent
  • RAM 2 GB system memory
  • Graphics Any GPU with WebGL 2.0 support
  • Network 3 Mbps — slight loading delay
  • Screen 1280 × 720 pixels
  • Frame Rate 30 FPS — some dropped frames during chases
  • Storage 150 MB for cache and assets

✅ Recommended — It Feels Right

  • Processor Quad-core 2.4 GHz or better
  • RAM 4 GB system memory
  • Graphics Dedicated GPU or modern integrated (Iris, Vega)
  • Network 10 Mbps — instant loads
  • Screen 1920 × 1080 or higher
  • Frame Rate 60 FPS — smooth camera, no input lag
  • Storage 500 MB free for smooth caching

🔧 What Actually Affects Performance

Six factors determine how smooth your run feels. Most players can fix the first two without buying new hardware.

01

Number of Open Tabs

Your browser shares memory between every tab. Five tabs open in the background can eat 1 GB of RAM that the game needs. Close everything else before you start a run.

02

Hardware Acceleration

If hardware acceleration is off in your browser settings, the game renders on the CPU instead of the GPU. This single setting is responsible for more lag reports than any other cause. Check it first.

03

Wi-Fi Signal Strength

The game streams assets on the first load. A weak signal means slow texture pop-in and stuttering when you enter a new zone. Move closer to the router, or switch to a wired connection for a stable 10 Mbps.

04

Screen Resolution

Rendering at 4K on an old laptop will kill frame rate faster than any other factor. If you experience stutter, drop your browser zoom to 100% or lower your display resolution to 1080p.

05

Browser Extensions

Ad blockers, VPNs, and script managers all inject code into the page. Some conflict with the game's input handling. Try a private window with extensions disabled to test for conflicts.

06

Device Thermal Throttling

Phones and laptops slow down when they get hot. A device that runs the game smoothly for five minutes and then stutters is almost certainly thermally throttling. Take the case off your phone, or play on a hard surface.

🚨 Common Problems & Fixes

Three issues account for the vast majority of player reports. Each one has a one-step fix that takes under a minute.

🐌

Game Feels Sluggish

Close background tabs, confirm hardware acceleration is on, and lower your display resolution to 1080p. This resolves 90% of lag reports without any hardware changes.

🎮

Controls Not Responding

Click once inside the game frame to give it input focus. Browsers do not send keyboard input to embedded frames until the user clicks. This is the most common "my keys do not work" cause.

🔊

No Sound

Browsers block autoplay audio until you interact with the page. Click the game once. If sound still does not play, check that the tab is not muted (right-click the tab to see the option).

🔍 How to Check Your Own Specs

You do not need to install a system info tool. Every modern operating system tells you what you need in a few clicks.

Platform Steps to Check What to Look For
🖥️ Windows Press Win + Pause/Break or right-click "This PC" → "Properties" Processor model, installed RAM, system type
🍎 macOS Click the Apple menu → "About This Mac" Chip, memory, macOS version
🤖 Android Settings → "About Phone" → "Software Information" Android version, RAM, processor model
📱 iOS / iPadOS Settings → "General" → "About" iOS version, device model
🌐 Browser Visit any WebGL test page, or check chrome://gpu WebGL 2.0 support, hardware acceleration status

✅ The Bottom Line

You do not need a gaming PC to play this. You need a device that does not fight you.

If your device was built in the last five years and can run a video call without dropping, it will run this game. The browser version runs on everything. The mobile app runs on any phone from 2019 or newer. The 3D Horror version is the only one that needs a little more breathing room.

If you can hit the recommended column — 4 GB RAM, 1080p screen, stable internet — you will never think about performance again. The game will just play. If you are on the minimum end, you can still finish every zone. You will just notice a dropped frame in the Cursed Mansion, and that dropped frame will not cost you a run if you plan ahead.

The single best thing you can do for performance is the simplest: close your other tabs. That one action is worth more than any hardware upgrade below the recommended tier.
